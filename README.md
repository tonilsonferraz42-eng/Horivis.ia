# HORIVIS

SaaS de automação de marketing e inteligência competitiva.

## Como rodar o projeto

### Comando único

```bash
npm run dev
```

Esse comando:

- limpa automaticamente as portas `3000` e `3001` se estiverem ocupadas
- sobe o backend em `http://localhost:3001`
- sobe o frontend em `http://localhost:3000`
-reinicia o backend automaticamente em caso de alterção em `backend/server.js`

Acesse: `http://localhost:3000`
